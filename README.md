# Paper Expression Editor Skill（论文去AI化表述）

[English](README_EN.md) · 中文

面向**研究生与本科生**的中文学术表达审查与润色 Skill，适用于不同学科的已有学术论文、学位论文、综述、开题报告及研究报告初稿。以研究生学术写作的严谨要求为默认编辑目标，识别模板化、机械化、重复和不自然的表达，说明具体问题并提供完整改写建议。在保留研究事实、专业术语、材料与数据、引用及结论边界的基础上，改善表达的准确性、逻辑性、连贯性和学术语气，并支持按目标中文期刊的写作要求适配。

## 核心能力

- **有依据的审查：**区分已确认问题、可选润色、格式偏好与待核验，正常学术句式允许保留。
- **保留信息的润色：**核对每项任务、论点、条件、关系与成果属性。改善语序、指代、搭配、衔接和段落组织，避免机械删词与过度压缩。
- **跨学科适配：**按理工实验、社会科学量化、质性研究、人文论证、综述等实际范式选择检查项，不强制所有稿件具有模型或实验。
- **目标期刊适配：**依据实际提供或查阅的规范及同类论文样例学习表达功能，保留作者文风。
- **完整可用的交付：**可只评阅、直接改写或边查边改；手动修改时给 Word 可搜索的连续原文、修改范围和完整替换稿。
- **双重复核：**按 `Lock → Diagnose → Decide → Revise → Audit`，先查信息与语义，再查改后段落是否连贯完整。

“去 AI 化表述”在本项目中指处理可观察的写作问题。常见开头、分号、并列与多动词仅是复查线索；严格体现为证据与保真，不以修改数量、术语数量或缩短篇幅体现严格。

## 使用

本仓库的 Skill 目录是 [`paper-expression-editor/`](paper-expression-editor/)。将**整个目录**复制到 Codex 个人技能目录（通常为 `~/.codex/skills/`），使入口成为 `~/.codex/skills/paper-expression-editor/SKILL.md`。也可用 Skill 安装器从本仓库安装这个子目录。安装后如未出现，可重新打开会话。

```text
$paper-expression-editor 请审查并润色这篇中文论文的讨论部分。我的领域是教育学，采用访谈研究。以研究生论文要求检查论证和表达，保留材料、直接引语及解释边界，区分必改问题与可选润色，给完整替换稿。
```

```text
$paper-expression-editor 请优化这段理工科论文的表达，允许拆句和调整段落组织。逐项保留研究任务、实验条件、指标、引用和结论强度，不为了去AI味机械缩短。用表格给连续原文与完整替换稿。
```

```text
$paper-expression-editor 请按我提供的目标期刊指南与两段同类论文样例润色摘要。说明实际采用的要求，保留研究事实与作者文风，不补造结果或贡献。
```

其他 AI 工具可复制 [`01-直接使用的主提示词.md`](01-直接使用的主提示词.md)，连同稿件使用。命名一个文件或提供仓库链接不保证 AI 已读取全部文件；需要参考指南时应实际上传或提供文件访问能力。

## 风格与编辑范围

- 公共默认按适用规范和表达功能判断。少分号、标题避免顿号、“作者等人”可由用户启用，不自动套用维护者个人偏好。
- 轻度润色处理局部；允许段落优化时可合理拆句、重组与整合真实重复。最小充分修改不要求最短稿，也不设固定字数比例。
- 摘要、正文与结论可复现同一研究主题，应根据章节职责判断冗余。计划、进行中与已完成严格区分。
- 只评价实际看过的材料；缺少研究依据时列出缺口，涉及内容或主张变化的建议单列待作者确认。
- 语言优化可服务高水平中文期刊投稿；研究创新、方法、证据、期刊范围和同行评审仍需实际判断，不承诺录用或检测结果。
- 遵守适用的学校、期刊或项目规范及 AI 辅助披露要求。
