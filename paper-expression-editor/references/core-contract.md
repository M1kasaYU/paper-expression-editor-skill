# 核心契约：语义保真与最小修改

本文件是保真编辑的单一规则来源。规则重复时以本文件为准。

## Lock：先建立 Meaning Lock

改写前从当前材料提取，不确定处写“待核验”：

```text
研究状态：拟开展／进行中／已完成
研究对象与方法：
比较对象、条件与范围：
数据集、样本、数字、单位与公式：
引用及其绑定主张：
观察结果与结论强度：
因果方向与不确定性：
作者术语与缩写：
禁止新增的信息：
```

Meaning Lock 不是重述全文，而是列出这次修改不能改变的锚点。

## Diagnose → Decide

候选模式不等于问题。对每个候选表达依次问：

1. 删除或改写后，事实是否变化？
2. 命题范围、比较维度或上下文关系是否变化？
3. 研究阶段、因果方向或不确定性是否变化？
4. 它是否只重复了已经明确的信息？
5. 它是否承担真实的段落结构功能？

决策只能是 `KEEP`、`REVISE`、`DELETE` 或 `AUTHOR_CHECK`。

## Revise：最小充分修改

- 词语问题优先改词语，句子问题优先改句子。
- 只有局部修改无法恢复清晰性时，才扩大到段落或章节。
- 不为了制造“人味”添加口语、错句、犹豫、失败经历或随机句长。
- 不把相关写成因果，不把局部结果写成普遍结论。

## Audit：不可变项目

改写后必须复查：事实、数字、单位、引用绑定、比较条件、术语、研究阶段、命题范围、因果方向、结论强度，以及原文没有的新信息。不能确认时输出 `UNCERTAIN` 或 `AUTHOR_CHECK`，不默认为通过。
