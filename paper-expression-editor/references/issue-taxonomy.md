# Issue Taxonomy：问题分类

层级说明问题发生在哪里，编号说明问题是什么。一个问题只登记一次，必要时同时记录层级与风险。编号描述已核对的影响，不把候选词、对称结构或多动词本身判为缺陷。

| 编号 | 类型 |
| --- | --- |
| E01 | 空转框架或无效过渡 |
| E02 | 同义重复或无信息复述 |
| E03 | 造成冗余、单调或掩盖差异的句架同构 |
| E04 | 过度显式衔接或主语漂移 |
| E05 | 无依据评价或结论强度升级 |
| E06 | 抽象名词堆叠、动作不具体 |
| E07 | 标题与段首重复 |
| E08 | 摘要与结论低信息重复 |
| E09 | 逻辑连接误用或推理跳步 |
| E10 | 命题范围扩大或条件丢失 |
| E11 | 研究阶段漂移 |
| E12 | 术语、缩写或模块名漂移 |
| E13 | 引用绑定风险 |
| E14 | 数字、单位、公式或图表锚点变化 |
| E15 | 过度修改 |
| E16 | 格式偏好未按适用规范统一 |
| E17 | 有效信息遗漏或迁移未落实 |
| E18 | 主张、任务或干预目标被替换为不同命题 |

交付类别用“已确认问题／可选润色／格式偏好／待核验”；状态 `CONFIRMED / PENDING / EXCLUDED` 分别表示已确认、待核验、已排除。可选润色不得因为有编号就写成必须修改。风险分级按 [事实复核](fact-check.md) 的 A–D 说明，仅在有用时报告。

记录格式：

```text
Issue ID: E11
Layer: L1
Status: CONFIRMED / PENDING / EXCLUDED
Risk: A / B / C / D
Action: KEEP / REVISE / DELETE / AUTHOR_CHECK
Evidence: 原稿中的连续原文与位置
```
