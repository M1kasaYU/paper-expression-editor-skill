# 输出格式

根据用户任务选择一种模式，不混合无关报告。

## Review Only

```text
检查范围与版本：
整体判断：
问题清单：位置｜Issue ID｜Layer｜Status｜连续原文｜依据｜建议
待核验与未检查：
```

## Minimal Edit

```text
原文：
最小修改稿：
修改理由：
Meaning Audit：
```

## Review + Revision

```text
原文与位置：
问题诊断：
Meaning Lock：
修改决策：KEEP / REVISE / DELETE / AUTHOR_CHECK
修改稿：
Meaning Audit：PASS / UNCERTAIN / FAIL / AUTHOR_CHECK
```

## Full Document Pass

先给已检查与未检查范围，再按章节处理。最后统一复核术语、数字、引用、摘要和结论，不把片段结果写成全文结论。

## Word-Friendly

每项必须给出章节、原稿中逐字连续的搜索串、问题类型、完整替换文本和待作者核验项。不要用省略号或自行改写的句子代替搜索串。
