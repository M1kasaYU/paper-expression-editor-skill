# 输出格式：诊断与完整可用的改写

按用户交付要求选择。短任务少量说明即可，不强制输出全部内部工作表。用中文解释，只有用户需要编号或统计时加载问题分类。

## 表格评阅或边查边改

```text
已检查范围与未检查项：
整体判断：最重要的具体问题，不判断作者来源
编号｜位置｜类别｜逐字连续原文｜实际影响或理由｜决策与修改范围｜完整替换稿/建议｜核对与缺口
```

类别区分：**已确认问题**、**可选润色**、**格式偏好**、**待核验**。需展示已排除候选时标“保留/已排除”；不将所有建议写成必须改的问题。类别与 `KEEP/REVISE/DELETE/AUTHOR_CHECK` 分别描述判断性质和行动。

规则：

- 搜索串从实际原稿逐字连续截取，不附文档文件名，不用省略号或改写文本污染定位。多处同文补章节或邻近文本。
- 整句替换给整句，整段替换给整段；仅改局部明确起止与替换片段。讲解节选不得冒充完整稿。
- 多句合并列出全部来源，跨段迁移明确目标位置与整合稿；未看到目标时只提建议。
- 正常内容可少量给 `KEEP` 理由，避免暗示所有学术句式都需去除；无需列全稿保留表。
- 核对注明保留的独立任务/论点及重要锚点，有信息或强度变化时标作者确认，不当作等价替换。

## 只评阅

提供范围、连续原文、具体影响与建议，不强制改写或输出评分。无法确认重复或证据时注明需要的上下文/来源。

## 直接改写

先给完整可用的稿件，再简述关键调整、信息核对及待确认项。有语义变化的候选单列，不混入成稿。

## 完整闭环示例格式

```text
原文与位置：
类别及诊断依据：
Meaning Lock：本次修改的关键锚点与信息单元
决策：KEEP / REVISE / DELETE / AUTHOR_CHECK
完整改写稿：
Meaning Audit：PASS / UNCERTAIN / FAIL / AUTHOR_CHECK
信息去向与段落质量：
```

## 长文与期刊适配

按章节分批，记录已查看与未查看范围。完成相关部分后核对术语、引用绑定、摘要与结论的强主张；只看节选不称全文通查。统计说明计数单位，不重复计算同一问题。

期刊适配注明实际规范/样例、已执行项、未核对项。表达审计通过不表示研究已被独立核验或达到录用标准。
