# 改后审计：信息保留与段落质量

先读 [核心契约](core-contract.md)。审计比较原文与实际交付稿，不再次凭词汇判断“AI味”。核对受修改影响的内容；后续修改只需重查相关锚点与衔接。

## 第一轮：有效信息与语义

| 项目 | 核对问题 |
| --- | --- |
| 独立信息 | 每项任务、论点、动作、验证安排、成果属性是否仍有去向？主题相同不足以证明信息完整 |
| 事实与材料 | 有没有增加、删除或改变数据、案例、材料来源、引语或事件？ |
| 数字与符号 | 数值、单位、精度、公式及指标方向是否保持？ |
| 引用绑定 | 引用是否仍支持同一主张？拆句后是否错配作者或扩大支持范围？ |
| 条件与范围 | 对象、样本、人群、时期、比较基线、前提与例外是否保持？ |
| 阶段 | 拟开展、进行中与已完成是否被混淆？ |
| 命题与关系 | 性能影响有没有变成文献主题？减少影响有没有变成消除传播？相关、因果、比较、时序与并行关系是否一致？ |
| 强度与术语 | 确定性、贡献范围、结论强度是否升级或弱化？作者概念与区分是否保持？ |
| 删除与迁移 | 删除确为冗余吗？迁移目标与整合稿是否明确、可用且不遗漏？ |
| 新信息 | 有没有原文未支持的机制、证据、文献、局限或结果？ |

## 第二轮：完整段落的可读性

- 主题与章节职责清楚，研究对象与动作、论点与材料能够对应。
- 指代可辨，句间关系合理；拆句不造成孤立片段，压缩不丢必要承接。
- 表述具体且保持学术语气，不用新套话替换旧套话；不强制所有段落同构。
- 替换范围完整，可直接用于用户指定位置；必要时回读前后文。
- 正常内容与作者风格得到保留。若语义保留但改后更生硬，继续修订或回退，不以删词数量证明质量。

## 状态与交付

- `PASS`：可见材料内未发现信息或语义漂移，且修改范围内段落质量检查通过。
- `FAIL`：已发现遗漏、无依据新增、命题变化或改后阅读障碍，先修复/回退，不交付为定稿。
- `UNCERTAIN`：缺少上下文或来源，无法确认等价性，说明缺口并保留安全部分。
- `AUTHOR_CHECK`：建议涉及作者需要决定的研究内容或主张变化，单列候选，不混入保真稿。

```text
Meaning Audit：
保留的信息与锚点：
删除/合并/迁移的依据（如有）：
发现变化或缺口：
段落质量核对：
```

简短任务可简述关键核对，无需输出全部工作表。`PASS` 不表示研究事实已由编辑者独立验证，也不证明全稿已达到某期刊录用标准。
