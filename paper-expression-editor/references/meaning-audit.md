# Meaning Audit：改写后语义审计

语义审计只比较原文与改写稿，不再判断文字是否“像 AI”。先读取 [核心契约](core-contract.md) 中的 Meaning Lock。

## 审计项目

| 项目 | 对照问题 |
| --- | --- |
| 事实 | 是否新增、删除或改写了研究事实？ |
| 数字与单位 | 数值、百分比、单位、精度和公式是否保持？ |
| 引用 | 引用编号、作者与相邻主张是否仍绑定？ |
| 条件与范围 | 数据集、样本、比较对象和实验条件是否保持？ |
| 研究阶段 | 拟、计划、将、预期是否被改成已完成？ |
| 逻辑 | 相关是否变成因果，解释是否变成事实？ |
| 结论强度 | “可能、较好、优于、证明、显著”等强度是否升级或弱化？ |
| 术语 | 作者术语、模块名和缩写是否被无依据替换？ |
| 新信息 | 是否加入原文没有的数据、机制、文献、局限或结论？ |
| 修改幅度 | 是否重写了没有问题的句子？ |

## 输出

```text
Meaning Audit: PASS / UNCERTAIN / FAIL / AUTHOR_CHECK
已保持：
发现变化：
需作者确认：
```

`PASS` 只表示当前材料中未发现语义漂移，不表示事实本身已经由编辑者独立验证。
