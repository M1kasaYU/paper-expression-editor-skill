# 写作风格档案：按证据记录并覆盖

本文件记录用户明确确认或从样例中谨慎观察到的写作习惯。优先级：学科或投稿规范 > 本次明确要求 > 用户确认 > 强观察 > 弱观察 > 默认建议。

## 证据等级

每项偏好必须标注：

```text
CONFIRMED_BY_USER：用户明确要求或确认
STRONG_OBSERVATION：多个样例稳定出现，且未被规范覆盖
WEAK_OBSERVATION：仅有少量线索，不得据此全局改写
NOT_INFERRED：没有证据，不主动推断
```

## 记录项目

1. 术语：沿用作者已有译名与缩写，不统一轮换近义词。
2. 人称：沿用原稿第一人称或客观陈述，不强制改。
3. 段首与段末：记录是否有稳定的组织习惯，不把一次出现当作全局规则。
4. 断句：记录作者习惯的逗号、句号与分号分工，不设全文字数配额。
5. 连接：记录常用过渡及其表达的真实关系，不批量替换。
6. 标题与图题：只在有目标格式或多个样例支持时统一。
7. 计划时态：保持拟开展、进行中和已完成的区分。
8. 保留与避免：记录用户明确希望保留或避免的句式，并说明适用范围。

## 默认档案（WEAK_OBSERVATION，可覆盖、可关闭）

中文叙述优先用逗号承接紧密分句、句号结束完整判断；同一自然段多个分号优先复查；小标题避免顿号枚举；正文作者叙述用“作者名＋等人[序号]”。以上是个人偏好，不是通用规范。参考文献、英文引文、直接引语、公式代码、关键词按各自规范另行处理。

使用方法：提供1-2段导师已改稿时，只把其中稳定且不违反规范的特征标为观察结果；无样例时默认生效，但须在报告中注明采用了默认偏好与排除项。不得从范例论文复制具体句子或替作者创造全局文风。
