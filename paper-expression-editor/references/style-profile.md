# 风格档案：公共默认与可选偏好

公共默认采用准确、清楚、自然的中文学术表达，保留作者已有文风与专业术语。依据本次明确要求、适用的学校/期刊规范与作者样例做调整；发现要求冲突时说明具体冲突，不默默覆盖或声称仍符合目标规范。

## 按证据记录

```text
CONFIRMED_BY_USER：用户明确选择的要求
VERIFIED_REQUIREMENT：实际核对的学校/期刊规范及版本
STRONG_OBSERVATION：多个相关样例支持的习惯
WEAK_OBSERVATION：少量样例的线索，不据此全局改写
NOT_INFERRED：无证据，不推断
适用范围：文体、章节或稿件
来源及冲突处理：
```

记录术语、人称、句子组织、过渡、标点、标题、图题、引用叙述与研究阶段。样例用于识别有功能的稳定写法，不要求每段同构，也不复制参考论文的句子。

## 中性公共默认

- 专业概念可必要重复，沿用已有译名、缩写与人称。
- 逗号连接紧密分句，句号结束完整判断，分号可分隔有层次的并列内容。按功能与实际阅读负担判断，不设段内数量阈值。
- 正文“作者等”与“作者等人”、标题中的顿号按适用规范和作者选择，不凭形式诊断表达缺陷。
- 不推断学历、学科或某刊要求的统一文风；研究生严谨要求不等于句子更长、术语更多或语气更强。

## 可选中文写作偏好：须用户启用

维护者曾使用以下习惯，公开使用时不自动生效：

1. 同一自然段多个分号优先复查，紧密短分句偏好逗号，独立判断偏好句号。
2. 小标题偏好避免顿号枚举，替换时保持原概念与并列关系。
3. 正文叙述偏好“作者名＋等人[序号]”。

用户选择后按范围执行。多个分号仅是复查线索，不直接判错；作者写法先区分人名、模型名和普通“等”。参考文献列表、引语、英文、关键词与公式代码按各自规范另行处理，不全局替换。
