# 学科、研究范式与文体适配

从现有材料识别学科、研究范式、文体、章节、研究状态与修改力度。按实际研究选择检查项，跨学科稿件可组合；无需用户先填完整问卷。研究生标准体现为论点准确、证据对应、范围明确、语言严谨，本科生使用时解释更清楚，保真要求相同。

## 按研究范式选择

| 类型 | 重点核对 | 避免的套用 |
| --- | --- | --- |
| 理工实验、方法研究 | 对象、变量、步骤、条件、比较基线、评价方向、机制解释的依据 | 不为增强贡献新增实验或机理，不把拟验证改成验证成功 |
| 社会科学量化研究 | 样本/人群、变量含义、设计与估计范围、相关与因果、统计结论 | 不将观察相关改成因果，不把特定样本推广到所有群体 |
| 质性与案例研究 | 材料来源、情境、受访者/研究者声音、编码或解释过程、反例 | 不把引语改写成逐字原话，不把个案解释升级为普遍规律 |
| 人文与理论论证 | 概念区分、论点、论据、史料/文本语境、解释路径与异议 | 不强制模型、实验与显著性，不把诠释写成作者或历史人物的确定意图 |
| 综述与综合研究 | 文献覆盖范围、分类依据、证据异同、现状与作者综合判断 | 不将并列文献串成未经支持的时间/因果链，不只为换句式改变被引主张 |

上述为适配线索，不是自动给稿件增加章节或研究项目的清单。未提供专业依据时，表达可改，内容疑点标待核验。

## 按章节职责判断重复

| 章节/材料 | 主要功能 | 允许保留的复现 |
| --- | --- | --- |
| 摘要 | 概括研究问题、处理方式与主要发现/主张，按文体与规范取舍 | 正文核心信息的简要再现，不能因此判重复 |
| 引言、背景 | 界定问题、说明现有认识与研究动机 | 必要定义与研究问题引出 |
| 综述 | 分类、比较并综合文献 | 相同分类标签或比较维度有助于读者核对 |
| 方法、材料、论证路径 | 交代研究怎样开展或主张怎样建立 | 步骤、概念与材料的必要重复，保证可理解性 |
| 结果、分析 | 呈现发现或分析依据 | 回指条件、材料、指标与比较对象 |
| 讨论、结论 | 解释或综合贡献、边界与未决问题 | 对核心发现的不同功能再现，避免只换词照抄 |
| 开题、计划类报告 | 说明拟研究什么、为什么、怎样开展和如何验证 | 目标、内容、关键问题与路线各有职责，主题相同不等于冗余 |
| 研究、项目报告 | 说明工作状态、成果、依据及使用范围 | 必要的栏目导航、阶段总结与成果对应 |

判断冗余时比较“相同信息 + 是否增加本章节需要的功能”。段落对称、多动词或同一研究主题反复出现，不单独构成删除依据。迁移依 [核心契约](core-contract.md) 落实目标位置与整合文本。

## 修改力度

- **轻度润色：**局部搭配、指代、语序、标点与冗余修正。
- **段落优化：**按用户授权拆句、重组、整合，保留独立信息与章节作用。
- **结构/内容建议：**涉及移动章节、补证据或改变研究主张，单列建议与确认事项，不默认为表达润色授权。
