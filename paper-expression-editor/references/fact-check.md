# 事实、材料与引用复核

按本次实际提供的材料核对，缺少记录或来源时标待核验。适用于各学科，不强制稿件具有统计分析或实验数据。

| 项目 | 核对动作 |
| --- | --- |
| 问题与任务 | 同一研究问题及各项独立任务/论点保持，不新增贡献，不因压缩漏内容 |
| 方法与材料 | 步骤、变量、假设、案例、史料/文本出处、访谈情境及原有解释保留 |
| 数字与单位 | 原文与已查看图表、摘要、结论的指标及单位一致，四舍五入有依据 |
| 比较与范围 | 基线、样本、人群、情境、时期、条件、例外与指标方向保持 |
| 统计与推断 | 统计意义按检验理解，通常意义按上下文理解；不凭“显著”一词断言统计错误，不把相关改成因果 |
| 引语与解释 | 直接引语不悄悄润色，观察、受访者说法与作者解释有区别，不把诠释改成确定意图 |
| 图表与引用 | 标题、符号、编号与主张绑定，未见图像不评视觉质量；未读引文不声称验证来源 |
| 研究状态 | 计划、进行中、已完成及预期承诺保持 |
| 规范与披露 | 遵守适用的学校、期刊和项目要求，不将辅助润色改称未经辅助 |

## 依改动风险选择复核范围

- **D 表面：**局部搭配、标点或确认空转起句，无实质变化，核对局部及前后承接。
- **C 格式：**选定的作者写法、标题、标点偏好；核对姓名、编号、概念及并列关系。
- **B 内容证据：**材料、数字、方法、图表、解释或局限发生变化，核对受影响段落与证据，缺少依据不直接写入。
- **A 主张：**研究问题、独立任务、贡献、因果、验证安排或结论强度改变，标 `AUTHOR_CHECK`，核对受影响的证据链与关联章节。

实际语义决定风险，不能因“只删几个字”自动归为 D。局部润色不要求重开全文；若影响摘要、结论或多处一致性，再检查这些相关部分。

## 交付前重点

删除引导语不能丢维度与依据；拆句后作者、方法、引用仍对应；压缩标题不丢概念；成果属性与验证指标有去向；改后冻结实际交付稿，任何后续变化重查受影响项目。

强主张找不到支持位置时标明缺口并保留原稿，可提供待确认的收窄建议。调整断言强度不是纯语言修改，不能自动降调后声称原意完全不变。

历史聊天可提取偏好与候选，不能代替当前文本或原始记录。不得沿用此前 AI 声称的全文位置、数量、机制解释与核验结果。
