# 事实与引用复核清单

语言润色完成后，检查下列项目。提供了什么材料，就核对什么；缺少原始记录时明确标注“待核验”。

| 项目 | 核对动作 |
| --- | --- |
| 研究问题 | 改写后仍回答原来的问题，未增加未经研究的新目标或贡献 |
| 方法与假设 | 模型名称、步骤、变量、前提、限制和因果关系没有被改写错 |
| 数字与单位 | 原稿、表格、图、摘要和结论中的同一指标一致；四舍五入有依据 |
| 比较与范围 | 比较对象、基线、样本、实验条件、指标方向及适用范围保持准确 |
| 统计表述 | “显著”“稳健”“提高”等词与实际检验、误差和重复实验相符 |
| 图表 | 标题、坐标、单位、图例和正文叙述一致；未见图像时不评价视觉质量 |
| 引用 | 原引用编号与相邻主张对应；新加的文献必须实际核验，不编造来源 |
| 原创与披露 | 不把 AI 辅助改称未受辅助的原创；遵守适用的学校、期刊或项目要求 |

## 表达调整后的重点复核

- **删除引导语后：**“从……看”是否承担比较维度或范围限定；删掉后不能把某一指标上的判断变成整体结论。
- **拆分长句后：**作者、模型、方法和引用编号仍一一对应。重新检查各分句的主语，不让相邻作者的方法或结论相互错配；“随后”“因此”等新增连接词必须有依据。
- **统一“等人”后：**只改作者叙述格式，姓名、原编号及编号范围不变。模型名称、普通列举中的“等”和文末文献作者列表不受批量替换影响。
- **压缩标题后：**检查方法名称、研究对象、并列与从属关系、综述范围是否保留。“等”不能替代概念核验。
- **调整研究计划后：**拟开展、正在开展和已经完成的工作严格区分，承诺强度不变。
- **报告修改幅度时：**根据实际差异说明是标点调整、引导语删除、句序调整或内容改写；若增删了词句或关系，不称“只改标点”。
- **使用历史聊天时：**它可提供偏好与检查线索，不能代替当前论文和原始记录。未看到当前稿件时，不确认历史 AI 报告中的位置、数量、技术解释或“全文已通查”结论。

## 遇到证据不足时

- 把可直接确认的文字修改和依赖额外事实的修改分开。
- 对需要补证据的句子写明缺少什么：原始数据、运行输出、统计方法、引文原文或作者判断。
- 不为了让稿件读起来完整而补造实验结果、效应大小、显著性、文献、失败经历或局限。
- 不把 AI 的复核描述成作者已经完成的人工核验。

## 改动分级与冻结核对

先给每个改动定级，再决定核对范围：

- D 表面：标点、冗余引导语删除，无科学含义变化，局部核对即可。
- C 格式偏好：分号、标题、等人写法统一，须有本次要求或规范依据，核对姓名编号与概念关系不变。
- B 证据方法：数字、样本、模型、分析、图表、局限的任何增删，重开受影响的段落与图表对照。
- A 语义契约：研究问题、贡献、因果、验证框架、结论强度的变化，重开全文证据链，标“待作者确认”，不直接定稿。

交付前冻结将要交付的准确文字：对照原文逐项核对数字、单位、引用编号、比较条件、因果词与计划状态词；改后复跑一次，改一字重验。摘要与结论的每个强主张必须回指正文证据位置，找不到位置就降调或标待核验。
