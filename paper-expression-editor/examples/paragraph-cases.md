# 完整段落案例：保留信息与积极润色

以下为教学用虚构文本，仅演示编辑决策。涉及事实均沿用例句，不作独立验证。

## 1. 理工研究：拆句而非删任务

原文：本研究拟分析不同负载下缓存命中率的变化，研究高峰时段请求积压主要发生在哪些环节，并研究批处理策略对响应时间的影响，同时在统一硬件条件下比较两种策略的吞吐量与内存占用。

完整改写：本研究拟分析不同负载下缓存命中率的变化，定位高峰时段请求积压的主要环节，并考察批处理策略对响应时间的影响。同时，将在统一硬件条件下比较两种策略的吞吐量与内存占用。

类别：可选润色 / REVISE。原句包含不同任务与验证安排，长句可以拆开，不凭动词数量诊断堆叠。

核对：三个研究任务、负载与高峰条件、统一硬件、两种策略、三个不同评价维度及计划状态均保留。稿件可以接近原长，无须压缩比例。

## 2. 社会科学量化：保留条件与非因果主张

原文：从本次调查的结果来看，在控制年龄和教育程度后，通勤时间与生活满意度仍呈负相关。进一步从样本情况来看，这一分析仅涉及甲市受访者，不包括其他城市居民，因此这一发现不能直接用于判断其他城市的情况。

完整改写：本次调查中，在控制年龄和教育程度后，通勤时间与生活满意度仍呈负相关。分析仅涉及甲市受访者，不包括其他城市居民，因此不能直接将该发现推广到其他城市。

类别：已确认问题 / REVISE。两处观察标签增加重复包装，保留调查来源、控制变量、相关方向与推广限制后精简。

核对：没有改成通勤导致满意度下降，也没有补显著性、样本量或新解释。局部条件与例外不丢。

## 3. 人文论证：改善指代，不补心理意图

原文：从文本论证角度看，作者在第二章引用地方志说明空间变化，又在第三章引用同一材料讨论身份认同。因此，这一材料两次出现并不只是重复，其功能在前后章节之间发生了变化。这个变化提示我们，分析时需要结合这个材料在具体论证中的位置。

完整改写：作者在第二章引用地方志说明空间变化，在第三章则借助同一材料讨论身份认同。这两次引用承担不同的论证功能，分析时需结合地方志在各章中的具体位置。

类别：已确认问题 / REVISE。结尾重复“变化”，指代泛化；合并同义判断，保留两个章节、同一材料与不同论证作用。

核对：没有推断作者心理或新增史实。若上下文中的“从文本论证角度看”承担与其他视角的对照，则应保留这个限定，不能照用本例删除。

## 4. KEEP：有功能的平行段落

原文：问卷分析考察变量之间的关联，并核对不同群体的差异。访谈分析解释受访者如何理解这些差异，并记录与主要解释不一致的材料。

判断：两个分析方式职责不同，并列有助于比较；不为了改变镜像句式削弱关联、解释与反例处理。语法清楚时保留。
