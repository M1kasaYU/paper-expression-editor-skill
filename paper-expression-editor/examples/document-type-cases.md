# 文体与研究范式案例

教学例句只展示保真边界，不表示研究已经成立。

| 场景 | 原文信息 | 必须保留的区分 |
| --- | --- | --- |
| 期刊实验论文 | 在给定温度范围内，两种材料的耐久性存在差异 | 温度范围、比较对象与差异性质；不改成材料甲在所有条件下更优 |
| 社会科学量化 | 在本样本中，两个变量相关，控制因素见方法部分 | 样本范围、相关关系与控制说明；不写成已证明因果 |
| 质性论文 | 部分受访者将工作压力归因于排班变化 | “部分”、受访者归因与研究者判断的区别；不改成排班导致所有人压力上升 |
| 人文/理论论文 | 本文将“共同体”作为分析概念，区别于材料中的日常用法 | 概念边界与使用层次；不为减少重复轮换成相近但不同概念 |
| 文献综述 | 三项研究使用不同材料，对同一问题有不同解释 | 来源、材料差异与解释差异；不合并成所有研究一致的结论 |
| 学位论文 | 摘要概括主要发现，讨论解释其范围与局限 | 相同主题可按章节职责复现，不直接判冗余 |
| 开题报告 | 计划比较两种解释，预期检验其在特定情境中的适用性 | 计划状态、比较性质、情境及不确定性；不能改成已验证 |
| 研究报告 | 已完成第一轮访谈，计划补充另一地区材料 | 完成与计划分别对应各项工作；不能将整段统一成完成语态 |

直接引语不得悄悄润色为新的逐字引文。需要释义时明确标为释义并保持出处；长篇重复或跨章节迁移应查看相关部分，不凭本例自动执行。
